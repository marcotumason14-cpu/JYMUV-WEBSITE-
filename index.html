1. What is BIOS?

BIOS stands for Basic Input/Output System. It is firmware stored on the motherboard that initializes computer hardware and prepares the computer to start an operating system.

Functions of BIOS

  1. Performs the Power-On Self-Test (POST).
  2. Detects installed hardware devices.
  3. Initializes system components.
  4. Determines the boot device.
  5. Starts the process of loading the operating system.

2. What is UEFI?

UEFI stands for Unified Extensible Firmware Interface. It is a modern firmware interface that initializes computer hardware and helps start the operating system. It replaces traditional BIOS firmware on most modern computers.

Features of UEFI

  • May provide a graphical interface and mouse support.
  • Supports the GPT partition scheme.
  • Supports modern storage devices and large drives.
  • Supports Secure Boot on compatible systems.
  • Offers flexible boot configuration options.
  • Can improve boot performance on supported systems.

3. BIOS vs. UEFI

Feature Legacy BIOS UEFI
Interface Usually text-based Text-based or graphical
Partition Scheme Commonly MBR Commonly GPT
Storage Support Traditional boot limitations Supports large GPT boot drives
Security Limited built-in boot security Can support Secure Boot
Mouse Support Usually keyboard only May support a mouse
Hardware Compatibility Useful for older systems Designed for modern systems

Why Choose UEFI?

  • Supports GPT and large boot drives.
  • Provides Secure Boot on compatible systems.
  • Offers modern hardware support.
  • Provides flexible boot configuration.

Why Use Legacy BIOS?

  • Supports some older operating systems.
  • May be required for older hardware.
  • Helps maintain compatibility with legacy systems.

4. Important BIOS/UEFI Settings

  1. Boot Order: Determines which device the computer tries to start from first.
  2. Boot Mode: Selects UEFI or Legacy BIOS mode when supported.
  3. BIOS/UEFI Password: Helps restrict unauthorized access to firmware settings.
  4. Date and Time: Sets the system clock.
  5. Storage Settings: Configures supported storage devices and controller modes.
  6. CPU Settings: Displays or configures supported processor options.
  7. Memory Settings: Displays or configures supported RAM options.
  8. Secure Boot: Helps prevent unauthorized boot software from loading.
  9. Virtualization: Enables processor features used by virtual machines.
  10. Save and Exit: Saves configuration changes and restarts the computer.

5. Safety Precautions and Setup Keys

Safety Precautions

  • Shut down or restart the computer properly.
  • Use the correct key to enter BIOS/UEFI setup.
  • Identify settings before changing them.
  • Record original settings before making changes.
  • Avoid changing unfamiliar options.
  • Save only necessary changes.
  • Exit without saving if you are unsure.

6. Boot Order and Boot Devices

Boot order determines which device the computer checks first when starting.

Examples of Boot Devices

  • USB flash drive
  • SSD (Solid-State Drive)
  • HDD (Hard Disk Drive)
  • DVD/CD drive
  • Network boot device

Steps for Changing Boot Order

  1. Restart the computer.
  2. Enter BIOS/UEFI setup.
  3. Open the Boot menu.
  4. Select the preferred boot device.
  5. Move the installation USB to the first position if needed.
  6. Save changes and exit.
  7. Restart the computer.

7. Windows Installation

Windows is an operating system developed by Microsoft. It manages computer hardware, software, files, and applications.

Minimum Requirements for Windows 10

  • Processor: 1 GHz or faster.
  • RAM: 1 GB for 32-bit systems or 2 GB for 64-bit systems.
  • Storage: At least 32 GB for newer Windows 10 versions.
  • Graphics: DirectX 9-compatible graphics device with WDDM driver.
  • Display: 800 x 600 resolution or higher.

Note: Standard Windows 10 support ended on October 14, 2025.

Safety Precautions Before Installation

  1. Back up important files.
  2. Ensure a stable power supply.
  3. Disconnect unnecessary external devices.
  4. Check system compatibility.
  5. Prepare a compatible bootable installation USB.
  6. Verify that the installation media works properly.
  7. Avoid interrupting the installation process.

8. Common Installation Problems

Problem Possible Solution
USB not detected Check the USB connection and boot order.
No boot device found Verify the boot mode and bootable device.
Missing storage driver Load the appropriate storage driver.
Installation freezes Check the installation media and hardware.
Disk not detected Check storage connections and controller settings.
Installation errors Verify compatibility and installation files.

9. BIOS/UEFI and Operating System Installation Procedure

  1. Check the computer hardware and compatibility.
  2. Back up important data.
  3. Prepare a bootable operating system USB.
  4. Restart the computer and enter BIOS/UEFI.
  5. Configure the correct boot mode and boot order.
  6. Save necessary settings and restart.
  7. Boot from the installation USB.
  8. Follow the operating system setup instructions.
  9. Select the correct installation drive and partition.
  10. Complete the installation and initial configuration.
  11. Install the required drivers and updates.
  12. Verify that the operating system starts successfully.

Warning: Formatting or deleting the wrong partition can erase important files. Always back up data first.

10. Conclusion

BIOS and UEFI are important firmware interfaces that initialize hardware and start the operating system. Understanding firmware settings, boot order, and installation procedures helps technicians install operating systems and troubleshoot common computer problems.

1. Introduction to Servers

What is a Server?

A server is a computer or software that provides services, data, or resources to other computers called clients through a network.

What is Windows Server 2022?

Windows Server 2022 is a server operating system developed by Microsoft. It provides security, networking, storage, and application services.

Why is a Server Operating System Important?

  • Manages users and computers.
  • Provides shared files and resources.
  • Improves network security.
  • Supports applications and services.
  • Helps administrators manage computers.

2. Guide Questions

1. What is a server?

A server is a computer or program that provides services and resources to other computers on a network.

2. What is Windows Server 2022?

It is a Microsoft server operating system used to manage networks, users, files, applications, and security.

3. Why is a server operating system important?

It is important because it manages network resources, protects data, controls access, and provides reliable services to users.

4. What preparations should be done before installing an operating system?

  • Check hardware requirements.
  • Back up important files.
  • Prepare the installation media.
  • Check available storage space.
  • Prepare network settings.
  • Make sure you have a valid license.

3. Windows Server 2022

Windows Server 2022 is an advanced server operating system with multiple security features, hybrid cloud capabilities, and a flexible application platform. It includes security improvements to help protect systems and data.

Editions of Windows Server 2022

Essentials

Designed for eligible small businesses with relatively simple server needs. It has licensing and hardware limitations.

Standard

Designed for physical or lightly virtualized environments. It supports common server workloads.

5. Server Management

Server management refers to the process of monitoring, maintaining, configuring, securing, and optimizing servers to ensure reliable and efficient operation.

Importance of Server Management

  • Ensures system availability.
  • Protects data and resources.
  • Improves server performance.
  • Helps prevent downtime.
  • Supports business continuity.

6. Types of Servers and Their Functions

1. File Server

Stores and manages files that users can access over a network.

Example: Shared folders in a school or office.

Function: Centralized file storage and access control.

2. Web Server

Hosts websites and delivers web pages through HTTP or HTTPS requests.

Example: A school website.

Function: Responds to browser requests.

3. Database Server

Manages and stores structured data for applications.

Example: A student information system.

Function: Organizes, retrieves, and updates data.

4. Mail Server

Handles sending, receiving, and storing electronic mail.

Example: An organization's email system.

Function: Manages email communication.

5. Application Server

Runs applications and provides services to users over a network.

Example: Business or school management software.

Function: Executes application logic and services.

6. Domain Controller

Manages user authentication and access in a Windows domain using services such as Active Directory Domain Services.

Example: A school computer login system.

Function: Controls domain accounts and permissions.

7. Key Responsibilities of a Server Administrator

  1. Installing and configuring servers.
  2. Managing user accounts and permissions.
  3. Monitoring server performance.
  4. Implementing security measures.
  5. Performing backups and recovery.
  6. Updating software and operating systems.
  7. Troubleshooting server issues.

8. Key Areas of Server Management

1. User Management

Controls user accounts, access rights, and permissions.

2. Security Management

Protects servers against threats and unauthorized access.

3. Backup Management

Creates backup copies of data to help restore information after accidental loss or failure.

4. Performance Monitoring

Tracks CPU, RAM, disk, and network usage to identify performance problems.

5. Maintenance

Installs updates, security patches, and other necessary server software improvements.

6. Disaster Recovery

Restores data and services after a major system failure or unexpected incident.

9. Installation Procedures of Windows Server 2022

  1. Prepare the computer. Check the hardware requirements and back up important files.
  2. Prepare installation media. Obtain official Windows Server 2022 installation media and create a bootable USB if needed.
  3. Boot from the installation media. Select the appropriate boot device in the computer's firmware settings.
  4. Choose language and settings. Select the required language, time format, and keyboard layout.
  5. Start installation. Select the option to install Windows Server.
  6. Select the edition. Choose the appropriate edition and installation option for your requirements and license.
  7. Accept the license terms. Read and accept the applicable license terms.
  8. Select the installation drive. Choose the correct disk or partition. Be careful because formatting can erase data.
  9. Install Windows Server. Wait for the installation to finish and allow the computer to restart.
  10. Set the Administrator password. Create a strong password when prompted.
  11. Configure the server. Set the computer name, network settings, date, and time.
  12. Update and secure the server. Install applicable updates and configure appropriate security settings.
  13. Verify the installation. Check that the server starts correctly and that the required services work.

10. Conclusion

Windows Server 2022 helps manage users, files, applications, networks, and security. Proper installation and server management help maintain system reliability, protect data, and improve performance.
